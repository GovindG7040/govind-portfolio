Work Highlight

Hybrid Conversational RAG Assistant — Architecture Deep Dive

Problem Statement: Standard RAG systems often suffer from retrieval failures — either missing relevant documents through dense-only search or producing noisy results without reranking. Conversational systems also lose context across turns without history-aware retrieval.

Technical Approach: Implemented a hybrid retrieval pipeline combining ChromaDB dense vector search (HuggingFace embeddings) with BM25 keyword retrieval. Retrieved candidates are then reranked using a Sentence Transformers CrossEncoder for precision. The pipeline uses LangChain LCEL (LangChain Expression Language) for composable, modular chains.

Conversational Memory: Each query goes through a history-aware reformulation step that rewrites the current question with full conversation context, enabling accurate retrieval across multi-turn conversations.
